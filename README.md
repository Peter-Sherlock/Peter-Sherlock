I explore the systems around language models: memory, tools, evaluation, and feedback. My work connects ideas about intelligence with software that can be inspected, tested, and improved.

### Selected work

**[Mentis](https://github.com/Peter-Sherlock/Mentis)** &nbsp; <sub>Agent collaboration</sub><br />An artifact-driven collaboration prototype for delegation, feedback, and inspectable evidence.

**[Veritas](https://github.com/Peter-Sherlock/Veritas)** &nbsp; <sub>Evidence evolution</sub><br />Exploring how research conclusions should change when their supporting evidence changes.

**[OrgPilot](https://github.com/Peter-Sherlock/OrgPilot)** &nbsp; <sub>Stateful coordination</sub><br />A replayable coordination kernel for events, dependencies, and organizational workflows.

Other explorations: **[TypeRAG](https://github.com/Peter-Sherlock/TypeRAG)** for retrieval experiments, and **[toggl-mcp](https://github.com/Peter-Sherlock/toggl-mcp)** for practical MCP tooling.

### Focus

Agent architecture · Retrieval & memory · Evaluation & reliability

I’m interested in systems that preserve context across steps, keep their constraints explicit, and use feedback to guide the next iteration.
