## A little about me

I’m an AI and software developer interested in what happens **after the first answer**: how agents keep context, use tools, and adapt as goals and evidence change.

- 🌱 **Building** small, practical prototypes around agent collaboration, retrieval, and memory.
- 🔎 **Exploring** how evidence, state, and feedback can make long-running workflows more useful.
- 🛠️ **Working with** `Python` · `LLMs` · `MCP` · `RAG` · `Git`
